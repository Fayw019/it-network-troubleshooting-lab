# IT Network Troubleshooting Lab

Cisco Packet Tracer troubleshooting lab demonstrating how I identified and corrected an IP configuration problem and restored network connectivity.

## 1. Failed Connectivity Test

An initial ping test was performed between the devices. The test failed with 100% packet loss, indicating a network connectivity problem.

![Failed Connectivity Test](01%20failed%20connectivity%20test.PNG)

## 2. Identifying the Incorrect IP Configuration

I investigated the network configuration and identified an incorrect IP address configuration on PC1.

![Incorrect IP Configuration](02%20Incorrect%20IP%20Configuration.PNG)

## 3. Correcting the Configuration

The incorrect network settings were corrected so that the devices were configured on the appropriate network.

## 4. Successful Connectivity Test

After correcting the configuration, I repeated the ping test. The devices successfully communicated, confirming that the network issue had been resolved.

![Successful Connectivity](Successful%20connectivity%20after%20troubleshooting.PNG)
